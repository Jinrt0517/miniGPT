# 豆包快捷小窗体验参考

调研日期：2026-09-24。范围为桌面端快捷小窗及相关设置，服务于 miniGPT 的交互设计。

本次核对了公开资料和官方网站，没有安装或操作豆包 Windows 客户端。因此，下文“Windows 已证实”指公开资料交叉确认，不代表已在用户当前安装版本中实测。不同版本的菜单名称和默认行为可能不同。

| 交互或功能 | 参考结论 | 证据范围 |
| --- | --- | --- |
| `Alt+Space` 唤起小窗 | 在其他应用中可通过默认快捷键打开豆包小窗，直接提问。 | 2024 年 Windows 介绍与 2025 年创作者实机演示一致，见 [1]、[2]。 |
| 自定义唤起快捷键 | 设置中提供快捷键配置入口。 | Windows 介绍明确说明可修改小窗唤起键，见 [1]。 |
| 快捷提问、翻译、写作辅助 | 小窗承担随时输入、获得回答的轻量入口。 | Windows 小窗说明和实机演示，见 [1]、[2]。 |
| 截图提问 | 公开实机演示使用 `Shift+Alt+A` 截图后提问。 | 见 [2]；该快捷键属于演示版本，不应据此保证当前版本默认值。 |
| 窗口置顶、显示/隐藏快捷键设置 | Windows 旧版教程记录了窗口置顶和“显示和隐藏窗口”的快捷键设置。 | 见 [3]；教程针对客户端窗口，不能直接推断小窗当前默认置顶。 |

较早资料还介绍了小窗搜索本地文件、启动应用的能力。本项目的核心需求是 ChatGPT 对话，暂不把本地搜索器纳入基础范围。

## 本项目范围：设计选择，不是豆包事实

| 优先级 | 设计选择 |
| --- | --- |
| 核心 | 默认 `Alt+Space` 显示或隐藏小窗；显示时聚焦输入框；注册失败时说明冲突并允许改键。 |
| 核心 | 每次从隐藏状态唤起默认新建对话，历史入口可继续旧对话；提供新建对话、固定窗口、设置入口。 |
| 核心 | 提供模型和思考强度选择，但实际选项必须取决于可用的 ChatGPT 接入方式及账号权限，不伪造不可用选项。 |
| 核心 | 设置里集中管理快捷键、开机启动、置顶和主题；小窗支持移动、调整大小。 |
| 核心 | `Esc` 隐藏；可设置点击外部自动隐藏。 |
| 核心 | 粘贴图片，按发送后提交；专注普通对话。 |
| 已移除 | 区域截图功能已按用户要求移除。划词、语音、屏幕共享与应用内容读取不纳入当前范围。 |

模型选择及多档思考强度来自 miniGPT 的用户需求，不能描述为已核实的豆包小窗功能。

## 尚未核实的细节

- 当前 Windows 版本中 `Esc`、再次 `Alt+Space`、点击小窗外部的准确行为。
- 初始窗口尺寸和位置、尺寸记忆、托盘和开机启动的默认值。
- 当前小窗的附件拖拽、图片粘贴、菜单布局和完整快捷键表。

网络上的快捷键汇总和“悬浮窗权限”教程存在互相矛盾、混用移动端设置的情况，未将这些信息作为实现依据。若要精确复刻用户正在使用的豆包版本，应以该版本的实际界面核对上述细节。
