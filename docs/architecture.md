# 实现说明

## 进程与模块

miniGPT 的渲染层使用本地 HTML/CSS/JavaScript；Electron 主进程负责全局快捷键、窗口、托盘、图片剪贴板和在线语录。渲染进程启用 `sandbox` 与 `contextIsolation`，关闭 Node.js 集成，仅能调用 preload 中的有限 IPC 接口。

| 模块 | 职责 |
| --- | --- |
| `src/main.cjs` | Electron 生命周期、窗口与托盘、设置、剪贴板附件、IPC 分发 |
| `src/codex-client.cjs` | App Server 进程、stdio JSONL 协议、请求超时和工具／审批拒绝 |
| `src/chat-service.cjs` | 账号与模型、聊天状态、取消、隔离校验、本地历史与上下文恢复 |
| `src/settings.cjs` | 设置白名单、值校验和原子保存 |
| `src/window-state.cjs` | 窗口状态持久化、显示器边界适配与缩放误差修正 |
| `src/quote-service.cjs` | 在线语录分类、来源回退、去重和缓存 |
| `src/renderer/app.js` | 对话、欢迎页、草稿、历史操作和界面状态 |
| `src/renderer/selection-control.js` | 基于原生选项数据的主题选择器与键盘交互 |
| `src/native/windows-taskbar.cs` | Windows 全屏场景下对 miniGPT 自身窗口的任务栏提示 |

主进程验证 IPC 发送者、页面 URL 和操作名称；拒绝新窗口与页面跳转。外部链接仅允许无嵌入用户名／密码的 HTTP(S) URL，并交由系统浏览器打开；登录链接进一步限制为受支持的官方 HTTPS 域名。Markdown 经本地打包的 DOMPurify 清洗后显示。

## 登录与聊天隔离

主进程通过 stdio JSONL 与本机官方 `codex app-server` 通信。登录由官方进程管理。账号返回值只取账号类型、邮箱和订阅类型；不会把令牌、原始错误日志或执行通道传给界面。

模型与 reasoning effort 来自 `model/list`，发送前再次校验；不维护写死的模型菜单。只有 ChatGPT 登录模式允许发送。本地设置使用临时文件后原子改名保存；每段聊天拥有本应用生成的 ID，不接受其他 Codex 会话 ID。

为纯聊天限制执行能力：禁用 shell、code mode、浏览器、计算机控制、MCP、插件、hooks 等功能；为继承的 MCP 逐个设置 disabled；thread 与 turn 均明确使用空 environments；只读、无网络执行沙箱；拒绝服务端工具与审批请求。模型服务自身的联网连接不属于执行沙箱的网络访问。

MCP 禁用配置通过嵌套对象 `mcp_servers: { [name]: { enabled: false } }` 合并到原配置。App Server 的 JSON 覆盖不解析 TOML 引号路径；配置读取结果中的可选空值也不能直接回写为 TOML，所以这里只覆盖启用标志，保留原服务器名称和连接配置。

连接阶段检查 App Server 返回的安全配置；创建会话后再次确认 `ephemeral: true`、空执行环境、只读且无网络的执行沙箱。不符合要求时停止连接并提示更新 Codex。每次生成默认最长等待 10 分钟。模型服务的联网与欢迎页语录请求独立于执行沙箱；这些限制不表示整个应用不联网。

## 对话、取消与历史

从隐藏状态唤起或显式新建时，渲染层收到 `new-conversation` 或执行同样的新建逻辑。新对话增加本地 generation 标记，并记录脱离当前界面的旧会话，防止旧发送结果或流式事件覆盖新聊天。隐藏过程中仍可完成当前回答；重新唤起若旧回答还在生成，会停止它并开始新聊天。用户需要先停止当前生成，再从历史列表切换到旧对话。

发送等待期间，界面先记下停止意图；在会话 ID 或活动生成可用时发送中断。停止按钮会进入等待状态，防止重复点击发送多个停止请求。中文输入法组合期间的 Enter 不触发发送。

历史列表按更新时间排列，可按标题搜索。单条删除无需确认，清空全部历史必须在应用内确认；搜索只影响显示，不缩小清空范围。渲染层在发送、生成或历史写入期间保护删除操作，主进程也拒绝生成或发送等待期间的清空。服务层先写入删除后的磁盘快照，再更改内存映射；写入失败保留记录以便重试。删除后的会话 ID 会被界面忽略，避免晚到事件恢复已删除记录。删除当前历史时保留尚未发送的草稿。

重启或断线重连后，不恢复远端临时会话 ID，而是用本应用保存的可见文本和附件重建上下文。历史文本作为用户提供的 JSON 背景输入，图片按历史消息编号重附；不恢复模型隐藏状态。历史 JSON 超过 800,000 字符，或累计恢复内容超过 40 MiB 的长度预算时会提示新建对话。当前输入也检查模型的图片支持能力、附件数量与大小。

## 数据与剪贴板

默认数据目录在发行版为 `%APPDATA%\miniGPT`，源码开发为项目 `.local-data`，可通过 `MINIGPT_DATA_DIR` 为测试指定独立目录。

| 相对路径 | 内容 |
| --- | --- |
| `settings.json` | 快捷键、主题、置顶、开机启动、跟随屏幕、Codex 路径、模型和思考强度 |
| `window-state.json` | 普通窗口矩形与最大化状态 |
| `welcome-quotes.json` | 分类轮换顺序、语录哈希、语录缓存与维基分类游标 |
| `conversations/conversations.json` | 会话、可见消息、已发送图片与文本附件内容 |
| `conversations/runtime/` | 隔离会话的工作目录 |
| `chromium/` | Electron 会话数据 |

设置、窗口状态、语录和历史通过临时文件后改名保存。历史保存采用版本化 JSON；损坏文件不会静默覆盖，而是提示用户备份和恢复。聊天文件没有应用层加密。清空历史会清除会话和已发送附件，保留设置、窗口状态及语录缓存，不删除其他 Codex 或 ChatGPT 会话。

用户在输入框粘贴图片时，主进程使用当前 Electron 的异步 `ClipboardItem` 接口读取图片，先保存为内存中的待发送附件；只有按发送后才交给聊天服务并保存历史。应用没有监听全局剪贴板。当前界面没有文件上传或粘贴图片按钮，也不支持拖放；主进程保留图片／文本选取接口供内部调用。

## 窗口与任务栏

Windows 窗口创建时使用 `type: 'toolbar'` 与 `skipTaskbar: true`，避开任务栏和 Alt + Tab，同时保留键盘焦点与缩放边框。关闭窗口默认隐藏到托盘；完全退出需使用托盘或设置中的退出动作。全局快捷键冲突只提示用户，不修改其他应用。置顶状态通过设置持久化；失焦隐藏只在未置顶时生效。开机启动仅支持打包版，以 `--hidden` 启动。

窗口移动、缩放后延迟 200 ms 保存，隐藏、关闭及退出等事件立即保存。最大化／最小化切换保留最后的普通窗口矩形；恢复时按显示器工作区裁切，避免旧显示器断开后窗口留在屏幕外。默认最小尺寸为 480 × 260 DIP，紧凑模式高度为 260 DIP，展开为 680 DIP。通过比较实际窗口边界修正 Windows 分数缩放造成的像素舍入，避免重启后持续变大。

首次显示优先恢复保存的位置。同屏再次唤起保留位置，普通窗口跨屏跟随鼠标时平移相对工作区位置并限制到可见区域。打开设置不会重新居中；紧凑窗口会先展开以容纳面板。

`windows-taskbar.exe` 在显示／聚焦 miniGPT 前检查前台窗口是否覆盖同一显示器的完整边界。它使用 `ITaskbarList2.MarkFullscreenWindow` 设置 miniGPT 自身的 shell 标记，由 Explorer 决定任务栏层级；不对 Explorer 或其他窗口执行隐藏、移动等操作。普通最大化窗口和系统桌面被排除，多屏比较采用物理坐标并容许少量缩放舍入误差。辅助程序失败时记录警告，不能保证所有全屏程序的表现。

源码启动和打包通过系统 .NET Framework C# 编译器构建辅助程序；发行包直接包含生成的 exe。

## 选择器与欢迎页

模型／思考强度选项仍由隐藏的原生 `select` 管理，自定义选择器在顶层 Popover 内显示，避免紧凑输入区裁切菜单。选择器提供 listbox 语义、活动选项、选中状态、方向键、Home／End、Enter／空格、Escape、Tab 与前缀定位；菜单按可用空间选择上下方向，长列表可滚动。连接中或发送／生成中禁用选择，修改后将模型和思考强度写入设置。

欢迎页通过 `quotes:next` 向主进程取语录，与聊天服务分离，不调用模型。七类入口按洗牌后的顺序轮换。优先请求一言 `https://v1.hitokoto.cn/`，分类限制为本次类型并校验内容长度、类型与 UUID；重复或失败时查询中文维基语录分类和页面修订，提取简短的顶层语录并过滤参考、误引等章节。

语录请求串行处理，一言调用最小间隔为 550 ms，每次 HTTP 请求超时为 6 秒。保存最近 500 个标准化文本哈希及最多 250 条来源明确的缓存；离线回退尽量避开最近 20 条，缓存不足时允许重复，没有缓存则显示离线提示。维基回退可能有多个顺序请求，因此完整回退时间可能超过 6 秒。

来源标签和原文 URL 作为普通文本／链接展示，语录不会进入聊天上下文。请求只携带分类、页名等查询参数，不携带账号、聊天消息或附件。界面使用请求序号忽略迟到的旧语录结果。自动提取与去重不等同于来源真实性审核，出处应通过原文链接核对。

## 验证范围

`npm test` 覆盖协议、配置、输入校验、取消、历史恢复及删除、剪贴板、窗口状态、设置和语录逻辑。语录测试注入模拟 fetch，不能验证外部站点的实时可用性。

Playwright／Electron 脚本覆盖生成按钮时序、选择器、历史操作、窗口恢复、任务栏、剪贴板与桌面连通性。大部分检查使用独立数据目录和隐藏窗口；任务栏测试会短暂显示专用全屏窗口。桌面启动仍可能读取本机登录状态和请求语录。只有显式启用 `MINIGPT_LIVE_TEST=1` 的 `test:desktop`，以及打包后运行的 `test:chat` 会发送真实订阅聊天并使用额度。具体命令及各项副作用见 [README](../README.md)。
